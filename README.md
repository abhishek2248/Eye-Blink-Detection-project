# **Eye Blink Detection and Automatic Face Capture**

## **Problem Statement**
Manual face image capture can be inconvenient and may require user interaction. This project aims to detect a person's face and eyes in real time using a webcam and automatically capture and save a face image when both eyes remain open for a specific duration.

## **Objectives**
- **Detect faces in real time using a webcam.**
- **Detect both eyes using Haar Cascade classifiers.**
- **Monitor whether both eyes are open.**
- **Automatically capture an image after 1 second of continuous eye detection.**
- **Save captured images with unique filenames.**
- **Provide real-time visual feedback during detection.**

## **Tools and Techniques**
- **Python**
- **OpenCV**
- **NumPy**
- **Haar Cascade Classifier**
- **Face Detection**
- **Eye Detection**
- **Webcam Integration**
- **Grayscale Image Processing**
- **Bilateral Filtering**
- **Real-Time Image Processing**
- **Automatic Image Capture**
- **Image Saving using `cv2.imwrite()`**

## **Conclusion**
The project successfully implements a real-time face and eye detection system using OpenCV. It detects faces and eyes through a webcam and automatically captures and saves an image when both eyes are detected continuously for 1 second. This project demonstrates the practical use of **Computer Vision and real-time image processing**.
